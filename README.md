# Inspección de extintores SDE — V7

Publique **los cinco archivos de la raíz** (`index.html`, `styles.css`, `app.js`, `logo-sde.png`, `README.md`) en la raíz de su repositorio de GitHub Pages.

V7: 15 columnas de inspección en el orden solicitado; 3 columnas son fechas editables y 12 son controles ✓ / X. Funciona en vista de escritorio y móvil. Incluye los campos nuevos en PDF, Word, imágenes y JSON. Las inspecciones anteriores se migran conservando los controles equivalentes y las fotos; los controles sin equivalencia quedan vacíos.

Si GitHub Pages muestra la versión anterior, fuerza la recarga del navegador (Ctrl+F5) o borra la caché del sitio. Los datos se guardan en este dispositivo (IndexedDB); exporta respaldos JSON regularmente.
